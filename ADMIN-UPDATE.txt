Important:
- The login server error in the beta was caused by res.cookie(...) being called even though the project does not use cookie-parser. server.js now writes the Set-Cookie header directly.
- The admin dashboard is now split into real pages: Overview, Bookings, Studio, Services, Gallery and Settings.
- The left rail is icon-only. Hovering an icon reveals its label; clicking navigates to that page.
- The public booking flow now records anonymous booking intent events. The tracker counts booking starts separately from WhatsApp/Call contact actions.
- notification_settings and booking_attempts are created automatically at server startup. The migration script is also provided for an explicit database migration.
- Run `npm run db:migrate-admin-dashboard` when you want to migrate the database explicitly.
